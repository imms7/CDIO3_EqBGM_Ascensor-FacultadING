# Datasheets de Componentes

Esta carpeta contiene las hojas de datos técnicas de los componentes electrónicos utilizados en el prototipo de ascensor accesible. Estos documentos permiten consultar las características eléctricas, mecánicas y de conexión necesarias para el diseño, montaje y validación del sistema.

## Componentes documentados

- **Arduino Uno R3:** utilizado como unidad principal de control del prototipo.
- **Servomotor DS04:** encargado de generar el movimiento de la cabina.
- **Finales de carrera:** empleados para detectar posiciones límite y detener el movimiento de forma segura.
- **Pulsadores:** usados para simular las órdenes de llamada y selección de piso.

## Importancia de los datasheets

Los datasheets permiten verificar valores como voltaje de operación, corriente máxima, distribución de pines, tipo de señal, dimensiones físicas y recomendaciones de conexión. Esta información es fundamental para evitar errores en el cableado, proteger los componentes y justificar técnicamente las decisiones de diseño del proyecto.

## Relación con el proyecto

En el prototipo de ascensor accesible, cada componente cumple una función específica dentro del sistema de control y seguridad. Por esta razón, la consulta de los datasheets ayuda a garantizar que el hardware seleccionado sea compatible con la lógica de funcionamiento, la alimentación disponible y las pruebas de operación realizadas.
